# Рынок sales-софта 2026: что берём как паттерн, что не покупаем

Выжимка исследования (июль 2026) для Продавца: как топ-инструменты продажников
устроены внутри, и что из этого встраиваем в СВОЮ систему (доска + боты),
не платя за чужие CRM.

## Главный вывод исследования
Рынок разделился на два лагеря: полностью автономные AI-SDR (11x «Alice»,
Artisan «Ava», AiSDR — сами ищут, пишут, шлют, бронируют встречи) и
гибридные платформы (ИИ делает ресёрч и черновик — человек утверждает).
**Данные 2026: объём исходящих AI-рассылок вырос ~×6, а доля ответов упала
на треть.** Больше отправки ≠ больше сделок. Выигрывает гибрид:
**ИИ готовит — человек отправляет.** Для соло-художника в Германии (UWG §7,
см. `leadgen.md`) полный автомат ещё и юридически закрыт. Наш путь — гибрид.

## Паттерны, которые крадём у лучших

### Pipedrive → activity-based selling (наш фундамент)
Продавец управляет не «сделками», а СЛЕДУЮЩИМИ ДЕЙСТВИЯМИ: у каждой сделки
всегда назначено следующее касание с датой; день продавца = список сегодняшних
действий, а не созерцание воронки. → У нас: железное правило next_action
на доске «Лиды» + блок «касания сегодня» в утреннем дайджесте.

### Close → последовательности касаний (sequences)
Дожатие — не импровизация, а серия: Д0 оферта → Д+3 короткое напоминание →
Д+7 новый аргумент (фото похожей работы) → Д+14 «закрываю вопрос?» (breakup).
На каждом шаге касание фиксируется. → У нас: Продавец предлагает следующий шаг
серии по счётчику touches и дате последнего контакта.

### Attio / folk → отношения, а не только сделки
Для соло с 20–300 контактами CRM — это память об отношениях: кто кого
порекомендовал, о чём говорили, дни рождения бизнеса (открытие, юбилей).
→ У нас: notes в карточке лида + связка с архивом клиентов из инвойсов
(повторные продажи существующим клиентам — самый дешёвый канал).

### Clay → ресёрч перед касанием (enrichment)
Топ-инструмент 2026 не шлёт больше — он ЗНАЕТ больше: собирает данные о
компании перед первым касанием. → У нас: перед офертой Продавец делает
WebSearch по бизнесу клиента (что за место, отзывы, стиль, соседи) и
вплетает в письмо 1–2 конкретные детали. Персонализация = конверсия.

### HubSpot → бесплатный уровень как запасной вариант
Если когда-нибудь понадобится внешняя CRM (команда, партнёр) — HubSpot Free /
folk (~$20/мес) достаточны. Пока НЕ нужно: наша доска в дашборде и есть CRM,
данные остаются в friedman.db рядом с финансами — этого не даёт ни один SaaS.

## ИИ-возможности 2026, которые реально применимы к FARBAHOLIX
1. **Драфты писем с ресёрчем** (гибрид: бот готовит → Slavik жмёт «отправить»).
2. **Голосовой ввод повсюду**: итоги звонка/встречи голосовым в бота →
   Whisper → карточка лида обновлена. Продавец «слышит» всю воронку.
3. **Ежедневное обучение с антиповтором** (дайджест) — ни один SaaS этого
   не делает под контекст конкретной воронки.
4. **Ассистент цены**: перед офертой — быстрый анализ (площадь, сложность,
   срок, платёжеспособность района) → вилка цены с аргументами.
5. **Разбор отказов**: раз в месяц ИИ читает причины ❌ и предлагает 1–2
   изменения в оферте/цене/канале.

## Чего НЕ делаем (осознанно)
- Не покупаем CRM/AI-SDR подписки — функции реализуемы в своей системе.
- Не строим массовую холодную рассылку (закон + падающая эффективность).
- Не даём ИИ отправлять письма клиентам без подтверждения владельца.
- Не плодим дашборды-игрушки: каждая новая панель должна отвечать на вопрос
  «какое действие сегодня?», иначе она не нужна.
