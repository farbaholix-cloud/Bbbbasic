# Немецкое право для художника-фрилансера (Freiberufler Künstler)

Справочный скилл для Вячеслава (Slavik) — совладельца farbaholix.de, работающего как **Freiberufler** (художественная деятельность, признана Finanzamt) со статусом **Kleinunternehmer** (§19 UStG), **gesetzlich krankenversichert**, **в KSK пока не состоит**.

## Как использовать этот скилл

Это справочник + помощник по переписке, **не замена Steuerberater**. Всегда:
1. Дай прямой, конкретный ответ на основе reference-файлов ниже.
2. Если вопрос упирается в конкретные суммы/решения с налоговыми последствиями (выбор между Kleinunternehmer и Regelbesteuerung, спорная квалификация Freiberufler/Gewerbe, расчёт налогов) — дай ориентир, но прямо скажи, что финальное решение/расчёт должен подтвердить Steuerberater.
3. Если речь о письме/заявлении в инстанцию — используй reference `letters.md` и при необходимости скилл `comms-and-docs` для оформления (DE/EN деловой стиль, шапка письма и т.д.). Этот скилл даёт **содержание и юридическую логику** письма, `comms-and-docs` — общий формат/тон.
4. Цифры (пороги, ставки, взносы) меняются ежегодно. В reference-файлах указан год последней проверки. Если вопрос касается актуальной ставки/порога и в файле нет данных за текущий год — **сделай web_search**, не угадывай.

## Жёсткие правила (не нарушать)

- **Никогда не публиковать и не вписывать в письма/документы**: IBAN, BIC, Steuernummer, личный налоговый ID — это уже зафиксировано как общее правило проекта farbaholix, действует и здесь.
- Не выдавай себя за Steuerberater и не давай окончательных налогово-оптимизационных рекомендаций ("точно переходи на Regelbesteuerung") — только "вот механика, вот пороги, решение — с бухгалтером".
- При любой неопределённости статуса (Freiberufler/Gewerbe для конкретного типа работ, например крупный коммерческий мурал по найму малярной техники) — explicitly flag as edge case, see `references/ihk-handwerk.md`.
