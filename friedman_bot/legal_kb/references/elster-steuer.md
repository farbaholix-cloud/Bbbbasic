# ELSTER, Steuererklärung, EÜR

## ELSTER — что это и зачем

ELSTER (ELektronische STeuerERklärung) — официальный портал немецкой налоговой для электронной подачи деклараций. Для Freiberufler обязателен для большинства подач (с некоторыми исключениями для бумажных форм в простых случаях, но на практике почти всё идёт через ELSTER).

Нужен ELSTER-аккаунт (один на человека, регистрация с PIN, который приходит по почте — занимает 1-2 недели на первичную активацию, это стоит учитывать при планировании сроков).

## Какие формы/декларации релевантны для Freiberufler + Kleinunternehmer

1. **Einkommensteuererklärung (ESt)** — обычная декларация о доходах физлица, куда включается доход от freiberuflicher Tätigkeit (через Anlage S — для свободных профессий, не Anlage G, которая для Gewerbe).
2. **Anlage EÜR (Einnahmenüberschussrechnung)** — упрощённый учёт "приход минус расход = прибыль", стандартный способ учёта для Freiberufler (полноценный баланс с двойной записью не требуется, если оборот не очень большой).
3. **Umsatzsteuererklärung** — для чистого Kleinunternehmer (без перехода на Regelbesteuerung) **не требуется** ни годовая декларация по НДС, ни Voranmeldungen — это одно из главных удобств статуса.
4. **Gewerbesteuererklärung** — не нужна, пока деятельность признана freiberuflich.

## Сроки подачи (актуально проверять каждый год — обычно)

- Стандартный срок для самостоятельной подачи (без Steuerberater): **31 июля** следующего года.
- С налоговым консультантом (Steuerberater) срок продлевается, обычно до конца февраля следующего за следующим года.
- При наличии особых обстоятельств можно запросить Fristverlängerung (продление) через ELSTER или письмом в Finanzamt.

## Steuernummer

- Выдаётся Finanzamt при подаче Fragebogen zur steuerlichen Erfassung (анкета о начале деятельности).
- Используется во всех счетах (вместо или вместе с USt-ID, см. kleinunternehmer.md).
- **Никогда не публиковать на сайте farbaholix.de и не вписывать в генерируемый контент** — это уже зафиксированное правило проекта.

## Практическое ведение учёта в течение года

Даже без сложной бухгалтерии стоит вести:
- Все исходящие счета (Ausgangsrechnungen) — с номером, датой, суммой
- Все деловые расходы с чеками/счетами (материалы, инструменты, поездки, реклама) — для EÜR
- Если есть оплата наличными или бартер (например, муралы в обмен на проживание в Испании) — справедливая рыночная оценка услуги всё равно должна попасть в учёт доходов (Sachbezug/Tausch считается налогооблагаемым доходом по рыночной стоимости полученного блага)

## Когда точно нужен Steuerberater, а не самостоятельная подача

- Первый год деятельности — чтобы не пропустить вычитаемые расходы
- Любая ситуация с потенциальным переквалифицированием Freiberufler→Gewerbe
- Бартерные сделки с иностранными партнёрами (мурал за проживание в Испании) — вопросы трансграничного НДС/учёта дохода
- Вопрос статуса Maik Füller в GbR

*Последняя проверка фактов: июнь 2026. Сроки подачи проверять заново каждый год — иногда продлеваются отдельными постановлениями.*
