# ИИ-инструменты: продажи + платформа агентов (проверено: июль 2026)

Справочник Директора. Два блока: (1) Hermes Agent как возможная платформа для
«мозгов» всей команды; (2) рынок ИИ-инструментов продаж. Данные устаревают —
при вопросах о «сейчас» делай WebSearch и обновляй выводы.

## 1. Hermes Agent (Nous Research) — кандидат на платформу команды

**Что это**: опенсорсный (MIT) самообучающийся агент,
github.com/NousResearch/hermes-agent. Зрелость высокая: ~218k звёзд, v0.19.0
(июль 2026), активные релизы, большая экосистема (awesome-hermes-agent, WebUI,
desktop-клиенты).

**Что умеет из коробки — и что это заменяет у нас**:
| Возможность Hermes | Что заменяет в friedman_bot |
|---|---|
| Гейтвей: Telegram, WhatsApp, Signal, email, 20+ платформ из одного процесса | весь рукописный python-telegram-bot код (bot.py-обвязка, jurist_bot, sales_bot, director_bot) |
| Скиллы по стандарту agentskills.io (SKILL.md) — наши пять баз знаний уже в этом формате | ensure_*_kb, ручная маршрутизация промптов |
| Память: FTS5-поиск по всем сессиям + LLM-сводки + модель пользователя (Honcho) | remember_*/окна реплик в таблицах *_messages |
| Встроенный cron с доставкой в любую платформу | job_queue-расписания (07:00 сводки и т.д.) |
| Сабагенты для параллельных работ | наша ручная оркестрация Директор→агенты |
| Любой LLM-провайдер: Anthropic, OpenRouter, Nous Portal, свой endpoint | привязка к Claude CLI |
| Работает на $5 VPS / serverless (Modal, Daytona — «спящие» окружения) | наш постоянный сервер |

**Чего Hermes НЕ заменяет** (остаётся нашим кодом, вызывается как инструменты):
- `friedman.db` со всеми таблицами (проекты, финансы, долги, воронка, инвойсы);
- генератор Rechnung PDF (`invoice.py`), финансовый отчёт (`finance_report.py`);
- дашборды «Капитанский мостик» / бизнес-пульт (`dashboard*.py`);
- голос: Whisper-транскрипция, TTS-цепочка.

**Оценка Директора — рекомендация к переезду**:
- Выгода реальна: −80% инфраструктурного кода, встроенная долгая память,
  один гейтвей вместо четырёх ботов, независимость от одного LLM-провайдера.
- Риски: миграция памяти/привычек, обучение владельца новому интерфейсу,
  молодой проект (быстрые релизы = ломающие изменения), самообучение скиллов
  надо держать под контролем (наши SKILL.md — источник истины).
- **Путь — гибрид, поэтапно**: (1) поднять Hermes рядом на сервере, подключить
  Telegram + наши пять SKILL.md как скиллы; (2) дать ему доступ к friedman.db
  и python-скриптам как инструментам; (3) месяц параллельной работы; (4) если
  устойчиво — гасить рукописные боты по одному. Решение о каждом этапе —
  владелец подтверждает.
- Полезное: OnlyTerp/hermes-optimization-guide — гайд по миграции, Telegram
  и созданию скиллов.

## 2. ИИ-инструменты продаж 2026 (фильтр: соло-художник, Германия, UWG §7)

Крупные платформы (Salesforce Einstein, HubSpot Breeze, ZoomInfo) — не наш
масштаб. Релевантное для одного человека с воронкой из муралов:

- **Lemlist** — персонализированный холодный аутрич с картинками/видео в
  письмах; сильно для креативного бренда (письмо с мокапом мурала на фасаде
  клиента). Осторожно: холодные письма бизнесу в DE — только с законным
  основанием (UWG §7, см. sales_kb/references/leadgen.md).
- **Sai (Simular)** — автономный агент для соло/малых команд: работает сразу
  в почте, LinkedIn, CRM и календаре без API-интеграций. Ближе всего к идее
  «агент вместо отдела продаж».
- **Reply.io (Jason AI)** — мультиканальные последовательности касаний;
  паттерн sequences у нас уже описан в sales_kb/references/tools.md.
- **Apollo** — база контактов + обогащение + секвенции в одном; для поиска
  ЛПР по типам бизнеса (кафе, застройщики, управляющие компании).
- **Smartlead** — деливерабилити и масштаб холодной почты; для нас
  избыточен, пока воронка единичная.

**Вывод для FARBAHOLIX**: не покупать платформу ради платформы. Паттерны
(sequences, enrichment, activity-based selling) уже воспроизводим своими
агентами почти бесплатно. Точечная польза: Lemlist/Sai для визуального
аутрича, когда лидов станет системно не хватать — и только после проверки
законности канала Юристом. Если переезжаем на Hermes — эти паттерны
реализуются его скиллами вместо подписок.
