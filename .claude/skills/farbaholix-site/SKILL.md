# farbaholix.de – how the site is built and deployed

The live pages are **not edited in Elementor**. Every page is generated by `farbaholix-site/build.py` and pushed as one `<!-- wp:html -->` block (template `elementor_canvas`). Edit the sources, rebuild, deploy.

## Sources (farbaholix-site/)
| file | what |
|---|---|
| `build.py` | page builders, URL map (`URL`, `LANG_PATH`), cases, press list (`PRESS`), schema.org graph |
| `lang_de.py` `lang_en.py` `lang_uk.py` | all UI/page texts per language (`L[...]`) |
| `cases.py` | project reports (FSV, Sankt Georgen): texts ×3 languages, gallery captions `CAP`, UI strings `UI` |
| `articles.py` | magazine articles (one page, anchors) |
| `gallery.py` | portfolio lightbox (50 works, captions ×3) |
| `calc_texts.py`, `calc.js` | price calculator (config `FX_CFG` at top of calc.js) |
| `fx.css`, `fx.js` | shared styles/scripts (lightbox, lamp effect, contact form + popup, call card) |
| `media_seo.json` | image key → WP media id/url (`img(key)` in build.py) |
| `imgs.json`, `keep.json`, `alts.py` | old portfolio images (`old(n)`) and their alt texts |
| `page_ids.json` | `<page>_<lang>` → WordPress page id |

`python3 build.py` writes `page_<page>_<lang>.txt` (WP content) and `local_<page>_<lang>.html` (local preview).

## Deploy
Credentials only via env: `FX_WP_USER`, `FX_WP_PASS` (admin account). Never commit them.
```
cd farbaholix-site && python3 deploy.py            # all 24 pages
python3 deploy.py home fsv                          # only some
```
`wp.py` logs in with cookies and gets a REST nonce from `admin-ajax.php?action=rest-nonce`. Plain Basic Auth does **not** work on this host.

## URLs & languages (Polylang)
DE is the default language without prefix (`/`, `/projekte/…`), EN under `/en/`, UK under `/uk/`. Home pages are Polylang front pages (option “front page URL contains language code” is on). Report pages are children of the projects page (`/projekte/fsv-frankfurt-stadion/`).
New page checklist:
1. Add builder + `URL[k][page]` (+ `PAGES`, `BUILDERS`), build.
2. Create via `wp/v2/pages` with `slug` (last URL segment), `parent`, `title`, `template: elementor_canvas`, `status: publish`; store id in `page_ids.json`.
3. Language + translations: `lang.set_lang(w, pid, lang, {'de': id, 'en': id, 'uk': id})` (posts the classic edit form; Polylang free has no REST for this).
4. SEO: `w.req('POST','rankmath/v1/updateMeta',{'objectType':'post','objectID':pid,'meta':{'rank_math_robots':['index','follow'],'rank_math_title':…,'rank_math_description':…,'rank_math_focus_keyword':…}})`.
   Rank Math checks the focus keyword **verbatim** in SEO title, description, URL slug, first paragraph, a subheading and image alt – pick a keyword that really appears there.
5. Front-page translations need an explicit `rank_math_canonical_url` (`/en/`, `/uk/`), otherwise Rank Math points them to `/`.
6. Redirects (Rank Math module is on): `rankmath/v1/updateSettings` with `{'type':'redirections','settings':{'sources':[{'pattern':'old-slug','comparison':'exact','ignore':''}],'url_to':'https://farbaholix.de/new/','header_code':'301','status':'active'}, 'fieldTypes':{}, 'updated':[…]}`.

## Media
`w.upload(path, alt_de)` → add `{key: {'id','url','alt_de'}}` to `media_seo.json`. Use WebP, SEO file names (`graffiti-frankfurt-…`), German alt. Background removal: `rembg` with `birefnet-portrait` gives clean hair/edges (model ≈1 GB, delete `~/.rembg/models` afterwards).

## Pitfalls we already hit
- WordPress texturize breaks inline JS (`&&` → `&#038;&#038;`): scripts ship as base64 `data:` URIs – keep it that way.
- Never post the classic edit form with `post_title=''` – it wipes titles.
- Python strings with Ukrainian/English apostrophes: use double-quoted strings (`"Об'єкт"`), editors may turn `'` into `’`.
- The “lamp” effect (`.fx.lights-on`) switches sections inside `.fx-lit` to a light background: every new text element there needs a dark `lights-on` colour rule, otherwise it is invisible.
- Maik’s own works/credits must not appear on the site; no home address; WhatsApp Business +49 151 724 50347; VAT is charged since 2026 (no Kleinunternehmer text).
- Sandbox browsers often fail to load farbaholix.de (`ERR_TOO_MANY_RETRIES`, proxy cert) – use `ignoreHTTPSErrors`, retry, or verify with `curl`/urllib instead of assuming the site is broken.

## Contact hub
WPCode snippet #918 = `wp-snippets/fx-contact.php`, push with `python3 wpcode.py` (check syntax first: `php -l`). Form (multipart, up to 4 images `img0..img3`, only real JPEG/PNG/GIF/WebP, stored in `uploads/fx-leads/`; sent to Telegram as a reply to the lead, attached to the e-mail, linked in WhatsApp; form also has the spray-progress + cheer animation in fx.js `fxExtras`) → `fx/v1/contact` → lead `fx_lead` (admin → Anfragen) + Gmail + WhatsApp (CallMeBot) + Telegram bot @Farbaholix_chat_bot. Slavik replies in Telegram with *reply* → website chat (`fx/v1/thread`, token in localStorage, fx.js) + e-mail copy. The bot is closed to strangers (they are pointed to @slavik_ffm); the site's Telegram button opens Slavik's personal account `TG_USER`. Setup/rotate token: `POST fx/v1/tg-setup {token}` (admin; returns a one-time owner link if no chat is set). Bot token lives only in WP options, never in the repo.

## Optional: Royal MCP
The site runs the Royal MCP plugin (`https://farbaholix.de/wp-json/royal-mcp/v1/mcp`, OAuth or API key). When it is added as a connector in claude.ai, a session can read/edit posts, pages and media directly – good for quick text fixes. Generated pages should still be changed through this build, or the next deploy overwrites manual edits.


## Hidden media archive (smi-bvb)
Pages `smi` (DE/EN/UK, slugs smi-bvb / smi-bvb-en / smi-bvb-uk) and `smiarchiv_de` (password-protected full texts) are noindex and must never be linked from any other page, menu or sitemap. Data in `smi_bvb.py`; full article copies in `farbaholix-site/archive/smi-bvb/` (gitignored, public repo). `deploy.py` skips pages whose build file is missing.
